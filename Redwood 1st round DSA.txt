Move Zeroes

Question:

Given an integer array, move all zeroes to the end while preserving the relative order of the non-zero elements.

The operation must be performed in place without creating another array.

Example:

Input:  [0, 1, 0, 3, 12]
[0,1,0,3,12]
 i j
 
 1 0 0 3 12
   i   j
   
 1 3 0 0 12
     i   j
	 
 1 3 12 0 0 
        i   j
 0,1,2,3,4
 
 i=0
 j=i+1
 n = len(input)
 while():
	#i points to index where zero is there
	while(input[i]!=0 and i<n):
		i+=1
	else:
		break;
	#j points to index where non zero is there
	while(input[j]==0 and j<n):
		j+=1#4
	else:
		break;
	input[i],input[j]=input[j],input[i]
	i+=1#3
	j+=1#5
	
	
 
 
 
   
Output: [1, 3, 12, 0, 0]
